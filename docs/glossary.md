# Glossary

The words the screens use, one name per thing (ADR 0068). A screen that needs a new word adds
it here in the same change.

| Word | Meaning | Not |
| --- | --- | --- |
| DocketWorks | This app | Docketworks, JM, Job Manager |
| Cost | What we pay: wages, materials, overheads | price, value |
| Revenue | What customers pay us | price, value |
| Book (time to a job) | Put a worker's hours on a job, so the job carries their cost | sweep, allocate, log; "charge" means billing the customer |
| Leftover time | Clocked time that isn't booked to any job yet | unallocated, unbooked |
| General work | The shop's own job for paid time that belongs to no customer job | |
| Clock in / clock out | When a worker starts and finishes for the day | |
| Approve (a day) | The office accepts a worker's day, so it is paid | |
| Wages including paid leave | Wages plus holiday, sick and public-holiday pay, spread over the hours worked; has a tooltip | loaded wages |
| Note (on a job) | Free text someone adds to a job's history | event |
| Update from Xero | DocketWorks fetching what changed in Xero | sync, synced |
